# Rock Paper Scissors Game

🎮 Interactive browser-based game built with JavaScript  

---

## 🚀 Project Overview

This project is a simple and fun **Rock Paper Scissors game** built as part of a software engineering course—while also being a personal project designed for my family to enjoy together.

It allows users to play against the computer in a classic game format with instant feedback and results.

---

## 🛠 Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  

---

## ✨ Features

- 🎲 Play Rock, Paper, Scissors against the computer  
- ⚡ Instant result display (win, lose, or draw)  
- 🤖 Randomized computer choices  
- 🖱 Interactive UI with user input handling  
- 📱 Simple, responsive layout  

---

## 🧪 QA & Logic Highlights

- Implements core game logic with conditional statements  
- Handles user input and game state updates  
- Ensures accurate win/lose/draw outcomes  
- Focus on clarity, simplicity, and user experience  

---

## 🎯 What I Learned

- Strengthened **JavaScript fundamentals** (functions, conditionals, events)  
- Practiced **DOM manipulation** and user interaction  
- Built a complete mini-app from concept to execution  
- Balanced **technical learning with user-friendly design**
